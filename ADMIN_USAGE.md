# ADMIN USAGE

Инструкция по admin bot и web admin panel.

## 1. Admin bot

Admin bot нужен для оперативной работы в Telegram.

### Доступ

Бот пускает только:

- Telegram ID из `ADMIN_ALLOWED_TELEGRAM_IDS`
- и/или пользователей из таблицы `admin_users`

### Разделы

Внизу доступны кнопки:

- `Заявки`
- `Пользователи`
- `Серверы`
- `Статистика`
- `Онлайн`
- `Помощь`

### Заявки

Раздел показывает новые запросы на пополнение.

Для каждой заявки доступны действия:

- `Подтвердить`
- `Отклонить`

После подтверждения:

- баланс пользователя пополняется
- пользователю уходит уведомление

### Пользователи

В разделе `Пользователи` бот попросит ввести:

- `Telegram ID`
- или `username`

После поиска откроется карточка, где можно:

- посмотреть баланс
- посмотреть статус
- посмотреть тариф
- посмотреть дату продления
- посмотреть трафик
- выдать тест
- активировать
- деактивировать
- назначить `Безлимит`
- назначить `50 ГБ`
- сделать ручную корректировку баланса

### Серверы

Раздел `Серверы` показывает:

- адрес сервера
- online/offline статус
- включён ли он локально в продажу
- число клиентов
- локальную нагрузку

Можно:

- синхронизировать список из Remnawave
- добавить сервер в локальную систему
- убрать сервер из локальной системы

### Статистика

Раздел `Статистика` показывает:

- активных пользователей
- пользователей в grace
- заблокированных
- тестовых
- новые заявки
- суммарный трафик
- топ пользователей по трафику

### Онлайн

Раздел `Онлайн` обновляет snapshot и показывает:

- пользователя
- сервер
- IP, если доступен через официальный API/fallback
- user-agent, если доступен
- последнюю активность
- online/offline

## 2. Web admin panel

Web panel удобна для более спокойной операционной работы.

Адрес:

```text
http://YOUR_HOST:8000/admin/login
```

### Авторизация

Используется логин и пароль администратора из `admin_users`.

### Разделы панели

- `Dashboard`
- `Пользователи`
- `Серверы`
- `Заявки`
- `Тарифы`
- `Транзакции`
- `Трафик`
- `Онлайн`
- `Настройки`
- `События`

### Dashboard

Показывает:

- активных
- пользователей в grace
- заблокированных
- тестовых
- новые заявки
- задолженность
- топ по трафику
- загрузку серверов

### Пользователи

Можно:

- искать по Telegram ID и username
- открывать карточку пользователя
- вручную корректировать баланс
- выдавать тест
- активировать/деактивировать
- назначать тариф
- смотреть транзакции
- смотреть заявки
- смотреть Remnawave subscription link и доступные серверы

### Серверы

Можно:

- синхронизировать Remnawave
- включать/исключать сервер локально
- задавать `max_clients`

`max_clients` нужен для корректного процента загрузки.

### Заявки

Раздел для обработки пополнений:

- фильтр по статусам
- подтверждение
- отклонение

### Трафик

Таблица подписок показывает:

- текущий план
- статус
- использованный трафик
- лимит
- дату следующего продления

### Настройки

Раздел хранит ключ-значение настройки системы.

Можно записывать:

- JSON
- числа
- строки

### События

Системные события помогают отслеживать:

- создание пользователей
- активации тарифов
- синхронизацию серверов
- обработку заявок
- ошибки уведомлений

## 3. Практический ежедневный сценарий администратора

1. Проверить `Заявки` и обработать новые пополнения.
2. Открыть `Dashboard` и посмотреть grace/blocked пользователей.
3. Раз в день открыть `Серверы` и при необходимости выполнить sync.
4. Следить за `Трафик` и `Онлайн`.
5. При необходимости работать с карточками пользователей через admin bot.
