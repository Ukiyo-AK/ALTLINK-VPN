# ADMIN USAGE

Инструкция по admin bot и web admin panel.

## Admin bot

Admin bot нужен для быстрой операционной работы в Telegram.

### Кто может войти

Доступ получают:

- Telegram ID из `ADMIN_ALLOWED_TELEGRAM_IDS`
- и/или пользователи из таблицы `admin_users`

### Основные разделы

- `Платежи`
- `Пользователи`
- `Серверы`
- `Аналитика`
- `Онлайн`
- `Помощь`

### Платежи

Раздел показывает историю пополнений.

Так как сейчас используется auto-stub оплата, ручного approve/reject больше нет:

- пользователь инициирует пополнение
- платёж автоматически зачисляется
- администратор видит историю и суммы

### Пользователи

Поиск работает по:

- Telegram ID
- username

В карточке пользователя доступны:

- статус
- баланс
- тариф
- дата следующего списания
- задолженность
- общий трафик
- трафик по `Белым спискам`
- назначенный 10 Гбит сервер
- выдача trial
- активация/деактивация
- ручная корректировка баланса
- применение тарифа `69 ₽`
- применение тарифа `200 ₽`

### Серверы

Раздел показывает:

- адрес и имя сервера
- online/offline статус
- локально включён или нет
- число клиентов
- нагрузку
- тип сервера

Доступные действия:

- sync с Remnawave
- включить/выключить сервер локально
- назначить тип:
  - `10 Гбит`
  - `Белые списки`
  - `Обычный`

### Аналитика

Раздел показывает:

- активных пользователей
- пользователей в grace
- заблокированных
- trial-пользователей
- выручку за 30 дней
- суммарный долг
- общий трафик
- whitelist-трафик
- топ по трафику

### Онлайн

Раздел обновляет snapshot и показывает:

- пользователя
- сервер
- IP
- устройство/user-agent
- inbound
- последнюю активность
- online/offline

## Web admin panel

Адрес:

```text
https://YOUR_HOST/admin/login
```

### Разделы

- `Dashboard`
- `Пользователи`
- `Серверы`
- `Платежи`
- `Тарифы`
- `Транзакции`
- `Трафик`
- `Онлайн`
- `Настройки`
- `События`

### Dashboard

Dashboard содержит:

- карточки по статусам пользователей
- выручку за 30 дней
- долг
- график статусов
- график выручки по дням
- график загрузки серверов
- график распределения типов серверов
- топ пользователей по трафику
- последние платежи

### Пользователи

В разделе можно:

- искать пользователей
- открывать детальную карточку
- корректировать баланс
- выдавать trial
- активировать/блокировать
- переводить между тарифами

### Серверы

В разделе можно:

- синхронизировать ноды из Remnawave
- назначать тип сервера
- включать/выключать его в локальной продаже
- задавать `max_clients`

### Платежи

Показывает историю входящих платежей и их статусы.

### Трафик

Показывает по каждому пользователю:

- тариф
- общий трафик
- whitelist-трафик
- начисления за whitelist
- накопленный долг

### Настройки

Раздел для произвольных системных ключей `key/value`.

Подходит для:

- feature flags
- UX-настроек
- служебных параметров запуска

## Пользовательский web portal

Эта версия проекта включает не только админку, но и пользовательский кабинет.

Адрес:

```text
https://YOUR_HOST/portal
```

### Как работает верификация

Для пользователя реализован вход через Telegram Login Widget.

Почему это хороший вариант:

- не нужен отдельный пароль
- сайт и бот сразу работают с одним и тем же Telegram-аккаунтом
- баланс, trial и тариф синхронизируются автоматически
- меньше точек отказа, чем у самодельного OTP-флоу

### Что умеет портал

- вход через Telegram
- проверка обязательной подписки на канал
- запуск trial
- пополнение баланса
- выбор тарифа
- просмотр серверов
- просмотр subscription link и QR
- просмотр истории платежей

## Рекомендуемый ежедневный сценарий администратора

1. Посмотреть Dashboard.
2. Проверить `Платежи`.
3. При необходимости сделать sync серверов.
4. Посмотреть `Трафик` и `Онлайн`.
5. При проблемах открыть карточку конкретного пользователя через admin bot или web panel.
