Базовый URL: {{ api_base_url }}

Передавайте персональный ключ в каждом запросе:

X-API-Key: altlink_префикс_секрет

Ключ создаётся в разделе API, показывается один раз и хранится на сервере только в виде хеша. Не передавайте ключ в query string и не используйте его во frontend-коде.

Проверка ключа

GET {{ api_base_url }}/client

Возвращает ID и название API-клиента, список scopes и срок действия. Секрет не возвращается.

Список пользователей

GET {{ api_base_url }}/users?active_only=true&limit=100&offset=0

По умолчанию возвращаются только пользователи с действующим платным или тестовым доступом.

ПараметрОписание
active_onlytrue по умолчанию; false включает неактивных пользователей.
plan_codeФильтр по коду текущего тарифа.
limitОт 1 до 200, по умолчанию 100.
offsetСмещение для постраничной загрузки.

Для продолжения используйте meta.next_offset, пока meta.has_more равно true.

Пример ответа с тремя основными scopes

{ "items": [ { "id": "36c9e70d-...", "updated_at": "2026-07-30T12:00:00Z", "telegram_id": 123456789, "status": "active", "access_active": true, "plan": { "code": "unlimited", "name": "Pro • ежемесячно", "is_trial": false, "period_days": 30 } } ], "meta": { "limit": 100, "offset": 0, "count": 1, "has_more": false, "active_only": true, "granted_fields": [ "users.plan", "users.status", "users.telegram_id" ] } }

Один пользователь

GET {{ api_base_url }}/users/{user_id}

Возвращает тот же набор разрешённых полей. Неизвестный ID возвращает 404.

Поиск по Telegram ID

GET {{ api_base_url }}/users/by-telegram/{telegram_id}

Рекомендуемый endpoint для проверки доступа при входе в другой сервис. Требует users.telegram_id и возвращает access_active, если ключу также выдано users.status.

Правила интеграции

Все даты передаются в ISO 8601 в UTC. Денежные значения передаются строками с двумя знаками после запятой.

Используйте access_active, а не только строковый статус, чтобы решать, положен ли пользователю бесплатный доступ.

Храните ключ только в секретах backend-сервиса. При утечке отключите клиент или перевыпустите ключ в админке.

Версия API закреплена в URL. Несовместимые изменения будут выпускаться под новым префиксом, например /v2.
