# BOT USAGE

Инструкция по клиентскому Telegram-боту `altlink`.

## Главное

Бот работает без slash-команд. Основные разделы доступны через кнопки:

- `Профиль`
- `Подписка`
- `Баланс`
- `Серверы`
- `Сайт`
- `Помощь`

## Первый запуск

1. Откройте бота.
2. Нажмите `Start`.
3. Бот покажет приветствие и попросит подписаться на Telegram-канал проекта.
4. Пока подписка на канал не подтверждена, дальше пройти нельзя.
5. После проверки подписки откроется главное меню.

## Профиль

Раздел `Профиль` показывает:

- Telegram ID
- статус пользователя
- баланс
- текущий тариф
- дату следующего ежедневного списания
- задолженность
- назначенный 10 Гбит сервер

## Подписка

В разделе `Подписка` доступны:

- запуск trial на 2 дня
- выбор тарифа
- персональная subscription link
- QR-код
- трафик и начисления

### Trial

- длится 2 дня
- доступен один раз
- автоматически назначает один 10 Гбит сервер

### Тарифы

Доступны:

- `Один сервер 10 Гбит • 69 ₽`
- `Безлимит • 200 ₽`

Тарифы списываются ежедневно:

- цена месяца делится на 30 дней
- списание происходит автоматически раз в сутки

Для тарифа `69 ₽`:

- выдаётся один автоматически назначенный сервер `10 Гбит`
- серверы `Белые списки` доступны отдельно
- `Белые списки` тарифицируются по `4 ₽ / ГБ`

Для тарифа `200 ₽`:

- доступны все активные серверы без ограничений

## Баланс

Раздел `Баланс` показывает:

- текущий баланс
- количество платежей в истории

Кнопки:

- `Пополнить баланс`
- `История платежей`

## Пополнение

Сейчас подключена тестовая заглушка внешнего платёжного сервиса:

- выбираете сумму
- платёж создаётся
- баланс пополняется автоматически
- запись сохраняется в истории

Позже сюда можно подключить реального внешнего провайдера, не меняя пользовательский сценарий.

## Серверы

Раздел `Серверы` показывает только те серверы, которые доступны именно этому пользователю.

Типы:

- `⚡ 10 Гбит`
- `Белые списки`
- `Обычный сервер`

## Сайт

Кнопка `Сайт` даёт ссылку на пользовательский web portal.

На сайте можно:

- войти через Telegram
- запустить trial
- пополнить баланс
- выбрать тариф
- получить конфиги и QR

Бот и сайт синхронизированы по одному `telegram_id`.

## Grace period

Если на очередное ежедневное списание денег не хватает:

- доступ не отключается сразу
- начинается grace period на 14 дней
- бот отправляет напоминания
- после окончания grace доступ блокируется

## Уведомления

Бот автоматически отправляет:

- о низком балансе
- о ближайшем списании
- о начале grace
- о задолженности во время grace
- о блокировке
- об успешном пополнении
- об окончании trial

## Если что-то не работает

1. Проверьте, подтверждена ли подписка на канал.
2. Проверьте, есть ли активный trial или тариф.
3. Проверьте, хватает ли баланса.
4. Проверьте раздел `Сайт`, если удобнее управлять подпиской через браузер.
