# BOT USAGE

Подробная инструкция по клиентскому Telegram-боту `altlink`.

## 1. Общая логика

Бот работает без slash-команд.

Основные разделы:

- `Профиль`
- `Подписка`
- `Баланс`
- `Серверы`
- `Помощь`

Reply keyboard используется только для верхнего уровня. Внутри экранов навигация идет через inline-кнопки.

## 2. Старт и регистрация

Откройте бот и нажмите:

```text
/start
```

После первого запуска бот:

- зарегистрирует пользователя в локальной системе
- привяжет аккаунт к вашему `telegram_id`
- покажет onboarding-сообщение
- откроет русское меню

## 3. Профиль

Раздел `Профиль` показывает:

- Telegram ID
- локальный статус
- баланс
- текущий тариф
- дату следующего продления
- задолженность
- расход трафика за текущий период

Из этого экрана доступны кнопки:

- `Мой тариф`
- `Пополнить баланс`
- `Мои заявки`
- `Получить тест`

## 4. Тестовый период

Если пользователь новый и ещё не использовал trial, кнопка `Получить тест`:

- активирует бесплатный доступ на 2 дня
- создаст подписку trial
- включит доступ в Remnawave

Если trial уже использован, бот честно сообщит об этом.

## 5. Подписка

Раздел `Подписка` показывает:

- название тарифа
- статус подписки
- текущий период
- дату следующего списания
- задолженность
- использованный трафик

На этом экране есть кнопки:

- `Безлимит 200 ₽`
- `50 ГБ за 100 ₽`
- `Показать ссылку`

Если на балансе недостаточно средств, бот сообщит об этом и предложит пополнение.

## 6. Баланс

Раздел `Баланс` показывает:

- текущий баланс в рублях
- напоминание о ручной схеме пополнения

Пополнение работает так:

1. нажмите `Пополнить баланс`
2. бот попросит отправить сумму одним сообщением
3. заявка попадет администратору
4. после ручного подтверждения баланс будет пополнен

## 7. Мои заявки

Раздел `Мои заявки` показывает:

- последние заявки на пополнение
- сумму
- статус
- дату создания

Статусы:

- `new`
- `approved`
- `rejected`
- `canceled`

## 8. Серверы

Раздел `Серверы` показывает локально активные серверы, доступные пользователю.

Для каждого сервера можно открыть:

- карточку сервера
- общую subscription link
- QR-код

Важно:

- официальный API Remnawave отдает нативную общую подписку со всеми активными серверами
- поэтому бот показывает список серверов отдельно, а subscription link и QR используют официальный общий subscription URL

## 9. QR-код

В разделе сервера есть кнопка `Показать QR`.

Бот отправляет PNG-картинку с QR-кодом для официальной подписки Remnawave.

## 10. Уведомления

Бот получает автоматические уведомления о:

- низком балансе
- скором списании
- начале grace period
- напоминании во время grace period
- блокировке доступа
- подтверждении пополнения
- отклонении пополнения
- приближении к лимиту трафика
- исчерпании лимита
- окончании trial

## 11. Помощь

Раздел `Помощь` кратко напоминает сценарий:

1. получить тест
2. создать заявку на пополнение
3. дождаться подтверждения
4. выбрать тариф
5. открыть раздел `Серверы` и использовать subscription link или QR

## 12. Что делать, если нет ссылки или серверов

Если бот пишет, что:

- нет активных серверов
- ссылка недоступна

это обычно значит одно из следующих:

- ещё не выдан trial
- не активирован платный тариф
- администратор не включил серверы в локальной системе
- доступ заблокирован

В этом случае:

- проверьте `Профиль`
- проверьте `Подписка`
- при необходимости пополните баланс
